# SkyRate

A responsive weather and currency app that you can install on your phone or computer. Built with plain HTML, CSS and JavaScript. No frameworks, no build tools and no API keys needed.

## Features

- **Weather screen:** search any city (it suggests matches as you type) or use your current location
  - Current temperature, condition, high and low, and feels-like temperature
  - Today's details: humidity, wind, pressure, UV index, rain chance, sunrise and sunset
  - Next 24 hours with a small temperature bar for each hour
  - 7-day forecast with a temperature range bar
  - Background color that changes with the weather: clear, night, cloudy, rain, snow, storm and fog
  - °C and °F switch
  - Recent cities for quick access
- **Currency screen:** a separate screen with its own colors
  - Converter for 150+ currencies with a swap button
  - Quick amounts: 1, 10, 100, 1,000 and 10,000
